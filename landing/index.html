Pricing

Priced under what a search saves, not around what it costs to run.

$5 / 50,000 credits
≈ $0.0001 per search 1 credit deducted per call, refunded automatically on a failed search

A search's own marginal compute cost is close to zero — one embedding and a matrix multiply against a model that's already warm in memory. The real constraint isn't infrastructure, it's whether querying beats the token cost of not querying. At typical model API pricing, a few thousand tokens saved is worth a fraction of a cent — so the price per call is set to clearly undercut that, not to price the compute.

Integration

One endpoint, three ways to call it.

# 1. sign up — returns an API key and a checkout link
$ curl -X POST https://api.observe-search.dev/v1/signup \
-d '{"email":"you@example.com"}'
 
# 2. search
$ curl -X POST https://api.observe-search.dev/v1/search \
-H "Authorization: Bearer obs_..." \
-d '{"query":"retry logic for a failed upload","repo":"axios"}'
