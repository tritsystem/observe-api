Privacy Policy

Last updated: August 2026

This describes what data OBSERVE Search API ("the Service") collects and how it's used. The Service is built for machine-to-machine use (API keys, not user accounts with profiles), so what's collected is deliberately minimal.

What's collected

  • Email address — collected at signup, used only to create your Stripe Checkout session and, if you contact us, to respond. Your API key is stored only as a one-way hash, not in reverse-recoverable form.
  • Search queries and usage — the text of queries you send, which repo (if any) was searched, and result counts are logged against your key's hash, to enforce credit balances and for debugging.
  • Payment information — handled entirely by Stripe; this Service never receives or stores your card details. See Stripe's privacy policy.
  • Private repository content — if you use /v1/private/index, the repository you point at is cloned and embedded to build your private search index. It is not shared with other API keys.

What's not collected

No advertising trackers, no third-party analytics beyond what's needed to operate the API and process payment (Stripe), no sale of data to third parties.

Data retention

Usage logs are retained to support billing accuracy and abuse investigation. You can request deletion of your account's data by contacting the address on the homepage.

Changes

This policy may be updated from time to time; the "last updated" date above reflects the most recent revision.
